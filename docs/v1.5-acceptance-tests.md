## CI matrix

`.github/workflows/ci.yml` should gate provider-specific specs:

```yaml
jobs:
  always-on:
    name: CI (no creds)
    steps:
      - run: pnpm install
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm test
      # Runs all 32 specs without sandbox creds: V1 regression + paykit-internal specs

  sandbox-vnpay:
    name: VNPay sandbox CI
    if: ${{ secrets.VNPAY_SANDBOX_TMN_CODE != '' }}
    steps:
      - run: pnpm test --filter=@vibecc/paykit-vnpay
        env:
          VNPAY_SANDBOX_TMN_CODE: ${{ secrets.VNPAY_SANDBOX_TMN_CODE }}
          VNPAY_SANDBOX_HASH_SECRET: ${{ secrets.VNPAY_SANDBOX_HASH_SECRET }}

  # similar for momo, zalopay
```
